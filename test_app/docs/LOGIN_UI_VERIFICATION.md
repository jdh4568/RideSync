# 로그인 화면 1단계

- 작업일: 2026-11-07
- Figma: https://www.figma.com/design/vdeCHSAx4g9YRVDcyfF7Sh/RideMate--Copy-?node-id=231-2239
- 승인 범위: 로그인 UI, 앱 진입점, 입력·키보드 처리, 상태별 Preview. 서버 변경 없음.

## 구현

- `RideMateApp` → `LoginRoute` → `LoginScreen`으로 진입한다.
- `AppContainer`의 ViewModel factory와 생명주기 기반 상태 수집을 사용한다.
- 아이디/비밀번호 입력, 비밀번호 마스킹, 다음/완료 키, 필수 입력 안내를 제공한다.
- 아이디 길이는 서버 LoginRequest의 50자 제한을 따른다. 입력을 임의로 trim하거나 비밀번호를 변형하지 않는다.
- 유효한 입력으로 제출해도 실제 요청이나 성공 화면 이동 없이 준비 중 안내만 표시한다. 회원가입도 준비 중 안내만 표시한다.
- 로딩 UI는 Preview 샘플과 향후 실제 요청 상태를 위한 표현이다. 실행 앱에서 모의 로딩이나 모의 성공을 생성하지 않는다.
- 입력은 ViewModel 메모리에서 회전 시 유지된다. 프로세스 종료 시 초기화되며 비밀번호는 디스크·Bundle·로그에 보관하지 않는다.
- 기존 연결 테스트 화면은 보존하지만 로그인 화면에서 접근 메뉴를 추가하지 않았다.

## 레이아웃·자산

- 로그인에만 밝은 테마 및 지정 팔레트를 적용하고 다른 화면 테마는 유지한다. 로그인 Route에서 어두운 시스템 바 아이콘을 사용하고 화면을 떠날 때 이전 설정을 복구한다.
- 배경·폼을 하나의 스크롤 영역에 두고 safeDrawing/IME 인셋은 한 곳에서 소비한다.
- 배경 높이는 가용 높이에 따라 조절한다. 폼은 최대 너비와 여백을 적용하고 버튼·입력란 높이는 콘텐츠에 따라 증가할 수 있다.
- 배경은 Figma 원본 PNG이며, `ContentScale.Crop`과 정렬로 하늘·산·호수 영역을 표시한다. 화면 전체를 확대/축소하지 않는다.
- User(231:2353), Lock(231:2337)은 디자인 컨텍스트의 원본 SVG를 내용 변경 없이 4배 해상도의 투명 PNG로 변환했다. 최초 노드 PNG export의 회색 배경은 Preview에서 발견하여 교체했다. 구분선(231:2359, 동일 자산을 양쪽 사용)은 해당 노드의 PNG이다. Android 기본 이미지 로더로 표시하며 앱에 SVG 라이브러리를 추가하지 않았다.
- SVG 원본은 `docs/design-assets/login`에 보존했다. 아이콘 변환에는 개발 환경의 Sharp를 사용했다(`sharp(svgPath, { density: 288 }).png()`). 120×120px 자산을 30dp 슬롯에 표시한다.
- 자산 4개는 `app/src/main/res/drawable-nodpi`에 포함한다. 임시 Figma URL은 런타임에 사용하지 않는다. 아이콘 표시 크기는 30dp, 구분선은 1dp 높이이다.
- Inter 폰트 파일은 제공되지 않아 Android Sans Serif를 사용한다. 한글 자형·폭은 Figma와 차이가 날 수 있다.
- 입력란은 접근 가능한 Material 라벨을 사용하므로 포커스/입력 상태에 따라 라벨이 위로 이동한다. 폰트 확대 시 로고는 Ride/Mate 사이에서 줄바꿈하도록 구성하고 스크롤을 허용한다.
- 실제 시스템 바를 앱 이미지로 복제하지 않으므로 OS 인셋과 폰트 설정에 따라 Figma 기준 위치와 달라질 수 있다.

## 검증

- Preview 정의: 390×844 기본, 320×640 글꼴 1.3/2.0, 600×960, 844×390 가로, 입력 오류, 샘플 로딩.
- Figma 원본 화면과 다운로드한 배경을 열어 확인했으며 모든 자산의 존재와 비어 있지 않음을 확인했다.
- `:app:assembleDebug :app:lintDebug --offline` 성공. lint 오류 0개, 기존 설정·리소스 관련 경고 19개(버전 안내, 중복 라벨, 미사용 색상, 런처 아이콘). 신규 라이브러리 추가 없음.
- `git diff --check` 통과. 서버 코드·설정·DB 변경 없음.
- Android Studio Compose Preview 7개를 실제 렌더링했다. 기본/작은/큰/가로 화면, 큰 글꼴, 입력 오류, 로딩 샘플의 정적 배치를 확인했다. 390×844, 320×640·1.3, 600×960은 100% 배율로 배경·로고·폼·아이콘 배치를 추가 확인했다.
- 작은 화면·가로 화면·큰 글꼴에서는 콘텐츠가 초기 뷰포트를 넘으며 단일 세로 스크롤로 접근하도록 구성했다. 정적 Preview 관찰과 스크롤·키보드의 실제 조작 검증은 구분한다.
- 에뮬레이터, 실기기 검증: 미실행. 연결된 adb 기기와 등록된 AVD, 설치된 시스템 이미지가 없다.
- 기기 모델·Android 버전·글꼴 설정·내비게이션 방식: 실행 기기 없음으로 미기록.
- 실기기에서의 이미지 크롭, 작은 화면/큰 글꼴, 키보드·스크롤·회전·시스템 바·TalkBack 검증은 남아 있다.
- API, 토큰 저장, WebSocket, 메인/회원가입 화면 이동은 2단계 이후 승인 범위이며 이번에 구현하거나 검증하지 않았다.
